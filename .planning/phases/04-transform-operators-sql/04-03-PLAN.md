<objective>
**Purpose:** Make built-in operators and published UDFs discoverable through a single API metadata endpoint (XFORM-01). Per D-05 discovery is API-only this phase (no console-web page). Per D-06 the catalog is unified — built-in operators plus published UDFs in one response, each tagged with its kind/source. Per D-07 each entry carries rich metadata (type, description, parameter schema, usage example) sufficient to author the YAML directly.

**Output:** A new `ConsoleTransformCatalogController` exposing `GET /api/console/transforms` returning `R<List<TransformCatalogEntryView>>`; immutable DTO records `TransformCatalogEntryView` + `TransformCatalogParam`; a `TransformCatalogSource` service that merges authored built-in operator descriptors (`BuiltinTransformCatalog`) with published UDFs from the registry; a `CoreConfig` bean wiring; and a controller slice test. Internal `V2_*` scalar functions (e.g. `V2_JSON_EXTRACT`) are NOT listed — catalog granularity stays operator/UDF level (D-12).
</objective>
