<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Live Catalog → new runs | Reload updates pools; failures must not corrupt last-known-good (D-11) |
| Snapshot resolver → in-flight run | Must ignore post-save catalog state (D-10) |
| Worker JVM → task_execution DB | Worker reads snapshot JSON only (D-07) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Tampering | Hot-reload mid-run | mitigate | Snapshot-scoped catalog decorator; IT proves isolation (D-10) |
| T-07-05 | Denial of Service | Reload failure loops | mitigate | DEGRADED state + last-known-good; surface reason to operators (D-11, D-26) |
| T-07-06 | Elevation of Privilege | Worker live catalog access | mitigate | Worker path rejects live resolve when distributed flag set (D-07) |
| T-07-SC | Tampering | ConnectionCatalogImpl changes | mitigate | HotReloadTests + ConnectionSnapshotIT gate |
</threat_model>
