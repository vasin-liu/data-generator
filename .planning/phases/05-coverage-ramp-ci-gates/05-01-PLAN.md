    <action>
      In `New-TestMatrixSummary`, while iterating rows, capture each row's `tier` (from the parsed row) alongside the computed `status`. Add to the returned/serialized `$summary` hashtable a `p0` block: `@{ total = $p0Rows.Count; green = (@($p0Rows | Where-Object { $_.green }).Count); pass = $p0Pass; rows = $p0Rows }`. Keep all existing fields (`generatedAt`, `gitCommit`, `totals`, `rows`) unchanged — the rollup is additive. Ensure `ConvertTo-Json -Depth` is deep enough for the nested `p0.rows` (raise Depth if needed).
    </action>
    <acceptance_criteria>
      - `target/test-matrix-summary.json` gains a `p0` object with `total`, `green`, `pass`, and `rows[]` (each `{id,status,green}`).
      - `p0.pass` is true only when all P0 rows have `green=true`; a `tier:P0` row that is partial/pending/missing/failed yields `green=false` and `pass=false`.
      - Existing summary fields are unchanged.
    </acceptance_criteria>
    <verify><automated>pwsh -NoProfile -Command ". ./scripts/lib/test-matrix-summary.ps1; $s = New-TestMatrixSummary -MatrixFile .planning/test-matrix.yaml -RepoRoot (Get-Location).Path; if (-not $s.p0) { Write-Host 'missing p0 block'; exit 1 }; if ($null -eq $s.p0.pass) { exit 1 }; if ($s.p0.total -ne 7) { Write-Host \"p0.total=$($s.p0.total)\"; exit 1 }; Write-Host \"p0.total=$($s.p0.total) p0.green=$($s.p0.green) p0.pass=$($s.p0.pass)\"; exit 0"</automated></verify>
