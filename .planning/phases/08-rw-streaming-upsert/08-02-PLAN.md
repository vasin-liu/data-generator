# Plan 08-02: Chunked JSON Row Source & NDJSON/Array Streaming Parser

## Objective

Add incremental JSON source reading for NDJSON and JSON array formats under explicit CHUNKED/STREAMING policies (RW-01, D-08, D-21).

**Output:** `ChunkedJsonRowSource` with format detection or explicit `format: ndjson | array` YAML knob; policy-aware `JsonSourceFactory`.

**Contract with 08-01:** Mirror `ChunkedCsvRowSource` / `CsvSourceFactory.create(..., policy)` patterns from 08-01 — same `ChunkedRowSource` interface, `usesChunkedRead` gate, and default chunk size 1000 (D-03). 08-02 depends on 08-01 landing first so JSON chunked sources follow the established CSV factory/pipeline contract.
