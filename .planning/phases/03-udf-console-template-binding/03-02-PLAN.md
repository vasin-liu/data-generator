<objective>
Expose the operator-facing UDF lifecycle over REST: a unified multipart upload that creates drafts, plus publish / deprecate / list / version-history endpoints returning the `R<T>` envelope, with structured `UdfRegistryException` error mapping and RBAC gating on mutations.

Purpose: UDF-05 requires console/API upload, list, version history, and publish/deprecate. This plan builds the `/api/console/udfs` surface on top of the Phase 2 `UdfRegistryService`/`UdfPublishService` and the persistence from 03-01.
Output: `ConsoleUdfController`, `UdfVersionView`/`UdfGroupView` DTOs, a `ConsoleApiAdvice` handler for `UdfRegistryException`, and a `ConsoleAuthorizationFilter` UDF branch.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/API client → `ConsoleUdfController` (multipart) | Untrusted multipart upload (file part + text fields + metadata) crosses into the service; governance-sensitive (code-bearing artifacts) |
| `ConsoleAuthorizationFilter` → console mutation endpoints | Role/permission boundary for UDF upload/publish/deprecate when security is enabled |
| `ConsoleApiAdvice` → HTTP response | Error bodies cross back to the client; must not leak internals while still carrying structured codes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Elevation of privilege | UDF mutation endpoints | mitigate | Add `/api/console/udfs` RBAC branch before the generic `/publish` branch; POST requires `TEMPLATE_PUBLISH` (operator-grade), GET requires `TEMPLATE_READ` (viewer-grade) (D-15) |
| T-03-02-02 | Tampering | multipart upload payload | mitigate | Upload creates a DRAFT only; governance gate (secret scan, dangerous-script scan, JAR manifest checks) runs at publish through `UdfPublishService` (D-07/D-21), not at the controller |
| T-03-02-03 | Spoofing / Tampering | `udfId`/`version` request params | mitigate | Registry validates reverse-DNS udfId + strict semver and rejects duplicate `udfId+version` (`UDF_DUPLICATE_VERSION`); controller adds no bypass (D-08) |
| T-03-02-04 | Information disclosure | list / version-history responses | mitigate | DTOs (`UdfVersionView`/`UdfGroupView`) never include `payload()` bytes; only metadata + lifecycle timestamps are returned (D-14) |
| T-03-02-05 | Information disclosure | error responses | mitigate | `ConsoleApiAdvice` returns `R.fail(message, violations)` with structured codes; the generic `Exception`→500 handler logs server-side but returns a bounded message (existing behavior) |
| T-03-02-06 | Denial of service | unbounded upload size | accept | Payload size limits / scanning quotas are explicitly deferred (03-CONTEXT Deferred Ideas); revisit if needed |
| T-03-02-SC | Tampering | maven/npm dependency installs | accept | No new package-manager dependencies are added in this plan; slopcheck N/A |
</threat_model>
