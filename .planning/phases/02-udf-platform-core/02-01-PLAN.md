<objective>
Establish the unified UDF registry domain model and programmatic service API. This plan delivers
UDF-01: stable ID, type (java-plugin, script, sql), semver version, lifecycle state, and
in-memory storage with publish/deprecate transitions. Downstream plans 02-02 and 02-03 wire
type-specific runtimes and governance; this plan owns the registry contract only.
</objective>

<execution_context>
**Runtime:** Windows + JDK 25 + Maven (`.\mvnw-jdk25.ps1`). Tests run embedded-first.
**Module boundary:** Domain in `data-generator-common/data-generator-core`; service impl in
`data-generator-service`. No calcite dependency in core UDF types.
</execution_context>

<context>
Locked decisions: D-01 (in-memory), D-02 (FSM), D-03 (common + service), D-04 (inline payload),
D-05 (multi-version, reject duplicate), D-08 (global, no tenant), D-15–D-19 (ID/version/resolve),
D-26 (structured errors: UDF_NOT_FOUND, UDF_NOT_PUBLISHED, UDF_DEPRECATED, UDF_DUPLICATE_VERSION).

Precedent: `TemplateLifecycleService` + `AuditService` patterns in service module; validation
errors like `TemplateV2Validator` list style — use typed `UdfValidationError` records instead.

Out of scope: JDBC persistence, Console REST, runtime refresh wiring (02-03), PF4J/script/sql
execution (02-02/02-03).
</context>

<acceptance_criteria>
- `UdfType` enum values: `JAVA_PLUGIN`, `SCRIPT`, `SQL` with stable `jsonName` matching roadmap strings.
- `UdfLifecycleState`: `DRAFT`, `PUBLISHED`, `DEPRECATED`.
- `UdfRecord` holds: udfId, version, type, state, payload (byte[]), metadata Map (sqlName for SQL type),
  registeredAt, publishedAt, deprecatedAt.
- `UdfRegistry` interface: registerDraft, publish, deprecate, list, find, resolve(udfId, Optional version).
- `InMemoryUdfRegistry` rejects duplicate udfId+version; resolve returns latest published when version empty;
  resolve throws `UdfRegistryException` with code UDF_NOT_FOUND / UDF_NOT_PUBLISHED / UDF_DEPRECATED for invalid states.
- udfId validated as reverse-DNS pattern (at least two dot segments, lowercase alnum + underscore segments).
- version validated with semver regex `^\d+\.\d+\.\d+$`.
- All new public types have copyright block, class Javadoc, public method Javadoc per repo rules.
</acceptance_criteria>
