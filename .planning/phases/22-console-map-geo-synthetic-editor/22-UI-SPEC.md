## Spacing Scale

Declared values (multiples of 4), aligned with Ant Design control density (`controlHeight: 36`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, caption margin under titles |
| sm | 8px | Compact gaps, breadcrumb margin, Alert inset |
| md | 16px | Default form field gaps, page content padding |
| lg | 24px | Section padding inside cards / split panes |
| xl | 32px | Layout gap between list pane and map pane |
| 2xl | 48px | Major page section breaks (rare on this phase) |
| 3xl | 64px | Page-level outer breathing room only if shell requires |

**Exceptions:**

| Exception | Value | Reason |
|-----------|-------|--------|
| Map canvas min height | 400px | Usable WebGL viewport on assets page and editor preview |
| Mini-map in asset picker | 200px height | Modal preview only; list remains primary |
| Split list pane min width | 320px | Keep name + featureCount readable |
| Touch / icon hit area | 36px (Ant `controlHeight`) | Match existing console; not 44px mobile-first |

## Typography

Exactly four roles, two weights (match `consoleTheme` `fontSize: 14`):

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 | Table cells, form values, Alert body, map attribution |
| Label | 14px | 400 | 1.5 | Form.Item labels, column headers (via Table) |
| Heading | 20px | 600 | 1.2 | `ConsolePageHeader` title (`Typography.Title` level 3) |
| Caption | 12px | 400 | 1.5 | Bbox summary, file size, seed meta, OSM attribution |

Do not introduce display/hero type on operator pages. No third weight.

## Color

60 / 30 / 10 split from existing theme tokens (light defaults; dark counterparts in parentheses).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#eef1f6` (`#070b14` dark) | Page / shell ambient background |
| Secondary (30%) | `rgba(255,255,255,0.82)` containers (`rgba(15,23,42,0.78)` dark) | List Card, map chrome, Modals, table surface |
| Accent (10%) | `#0071e3` (`#06b6d4` dark) | Reserved elements only — see list below |
| Destructive | `#d70015` (`#f87171` dark) | Delete confirm OK, 409 error emphasis |
| Warning | `#b45309` (`#fbbf24` dark) | Honesty Alert (`type="warning"`), asset-id-wins inline warning, BBOX/CIRCLE guide strokes |
| Success | `#248a3d` (`#34d399` dark) | Upload / preview-fetch success toasts only |

**Accent reserved for (and only for):**

1. Primary CTAs — **Upload GeoJSON**, **Confirm asset**, **Preview sample** (when shown as primary Button)
2. Selected list row highlight / Table `rowHoverBg` affinity
3. MapLibre fill/line for **selected uploaded asset** geometry
4. Nav active state / links (`colorLink`)
5. Synthetic preview **point** circle fill (capped sample dots)

**Not accent:** basemap tiles, OSM chrome, disabled controls, secondary Buttons, honesty Alert background (use Ant Design `Alert` `warning` / `info` semantics).

### Map layer paint (locked defaults)

| Layer | Paint | Notes |
|-------|-------|-------|
| Asset fill | Accent at 25% opacity | Polygons from GET geojson |
| Asset line | Accent solid, width 2 | Polygon outlines + LineString |
| BBOX guide | Warning stroke, dashed `[2, 2]`, fill 10% | Client Turf rectangle (D-07) |
| CIRCLE guide | Warning stroke, dashed, fill 10% | Client `@turf/circle` (D-07) |
| Synthetic points | Accent circle radius 4–5px, white stroke 1px | From capped server preview (D-08) |
| Basemap | OSM raster `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | No Mapbox token (research + discretion) |

Always show OSM attribution in map footer Caption (12px).

## Copywriting Contract

All strings via i18n keys under `geoAssets.*` / `source.geoSynthetic.*` (zh-CN + en). English below is the contract source; Chinese must be equivalent meaning, not literal machine paste.

| Element | Copy (en) |
|---------|-----------|
| Primary CTA | **Upload GeoJSON** |
| Nav label | **Geo assets** |
| Page title | **Geo assets** |
| Page subtitle | **Upload and preview hosted GeoJSON used by geojson and geo_synthetic sources** |
| Empty state heading | **No geo assets yet** |
| Empty state body | **Upload a GeoJSON Feature or FeatureCollection to preview it on the map and bind it from the template editor.** |
| Error — list/load | **Could not load geo assets. Check the service and try again.** |
| Error — map GeoJSON | **Could not load map data for this asset. Refresh or re-select the row.** |
| Error — upload | **Upload failed: {serverMessage}. Fix the file or limits and retry.** |
| Error — preview path | **Could not resolve path/classpath for preview. Prefer an uploaded asset-id or fix the location.** |
| Destructive — delete confirm title | **Delete geo asset?** |
| Destructive — delete confirm body | **This permanently removes “{name}”. Templates that still reference it will block delete.** |
| Destructive — confirm OK | **Delete** |
| Destructive — 409 Modal title | **Asset is still referenced** |
| Destructive — 409 Modal body | **Cannot delete “{name}”. Referenced by: {usageList}. Remove or retarget those templates first.** |
| Honesty — sampling (D-09/D-10) | **Preview sample: up to {cap} points (seed {seed}). This is not a full pipeline run.** |
| Honesty — geometry only (D-11) | **Map preview only — not a full pipeline run.** |
| Asset-id wins warning (D-16) | **Both asset-id and path are set; asset-id is used at runtime.** |
| Asset picker title | **Select geo asset** |
| Asset picker confirm | **Use this asset** |
| Preview sample CTA | **Preview sample points** |
| Source kind label | **Geo synthetic (points)** |

### Seed honesty Alert placement (non-negotiable)

- Persistent `Alert` **at the top of the map preview region** whenever any preview content is shown (D-09).
- Sampling active → full D-10 wording (cap + seed when present + not full run).
- Guides/underlay only → shorter D-11 wording.
- `type="warning"`, `showIcon`, marginBottom `sm`/`md` (8–16px). Never dismissible via close icon while preview remains active.

## Screens & Layout

### S1 — Geo assets page (`/geo-assets`) — GEO-07

| Region | Spec |
|--------|------|
| Shell | Existing `ConsoleLayout` top dock; add nav item after UDFs, before Audit |
| Route | `<Route path="geo-assets" …>` inside `ConsoleLayout` (mirror `udfs`) |
| Header | `ConsolePageHeader` + **Upload GeoJSON** primary Button in `extra` (D-03) |
| Body | **Left ~40% / min 320px:** asset `Table`. **Right ~60%:** map panel (D-01) |
| Split | Ant Design `Row`/`Col` or CSS grid; gap `xl` (32px); both panes in glass `Card` |

**List columns (D-02):**

| Column | Required | Notes |
|--------|----------|-------|
| name | yes | Primary identity |
| featureCount | yes | From list API |
| bbox summary | yes | Compact Caption; e.g. `[minLon, minLat, maxLon, maxLat]` or humanized short form |
| contentType | if API exposes | Else omit — do not invent |
| size / byteSize | if API exposes | Else omit |
| actions | yes | Inline **Delete** link/button (D-04) |

**Interactions:**

1. Row click / select → fetch `GET /api/console/geo-assets/{id}/geojson` → MapLibre geojson source + fill/line → `fitBounds` via `@turf/bbox` (D-05).
2. Upload Button → Modal (UDF-style): file accept `.geojson,.json`, optional name field, multipart `POST /api/console/geo-assets` → success toast → invalidate React Query → select new row.
3. Delete inline → confirm Modal → on **409** replace with usage-hints Modal (template id/name) — no soft-delete (D-04).
4. Empty list → Empty state copy; map shows basemap only + short honesty hint optional or blank canvas message “Select an asset”.

### S2 — Template editor `geo_synthetic` fields — GEO-13

| Region | Spec |
|--------|------|
| Integration | Extend `SourceFieldsForm` + `SourcesStep` kind picker — **no** separate geo wizard (D-13) |
| Kind | Add `geo_synthetic` to `EditableSourceKind` / `EDITABLE_SOURCE_KINDS` |
| Layout | Mode `Select` first; remaining fields switch by mode (D-14) |

**Mode-switched fields (D-14):**

| Mode | Fields |
|------|--------|
| BOUNDARY (boundary points) | `boundaryAssetId` and/or path; seed; count; related boundary options |
| LINE (network sample) | `networkAssetId` and/or path; seed; count; related line options |
| BBOX | bbox params; seed; count |
| CIRCLE | center + radiusMeters; seed; count |

- Asset role: **Pick asset** Button opens asset picker Modal (D-15).
- Path role: reuse `SourceFileInput` / path Input patterns from `geojson` kind.
- When both asset-id and path set for same role → asset-id wins + inline `Alert type="warning"` (D-16).
- Keep `geojson` vs `geo_synthetic` kinds separate — never collapse (code_context).

**Editor map preview (equal depth GEO-12):**

- Collapsible or side panel below/beside fields: shared lazy `GeoMapPreview`.
- Underlay: asset-id → same GET geojson; path/classpath → **server preview helper** returns GeoJSON (D-06) — console must not reimplement resolve.
- BBOX/CIRCLE guides: client Turf only (D-07).
- Optional **Preview sample points** → `POST …/preview/synthetic` (cap ≤500) (D-08); show seed in honesty Alert.

### S3 — Asset picker Modal (D-15)

| Element | Spec |
|---------|------|
| Width | `720px` (Ant `width={720}`) or `large` |
| Body | Left: Table (name, featureCount). Right: optional mini-map (200px) when map chunk loaded |
| Fallback | If map chunk not yet loaded / failed: list-only + Caption “Map preview unavailable” — picker still usable |
| Confirm | **Use this asset** writes `boundaryAssetId` / `networkAssetId` / `assetId` as applicable |
| Cancel | Close without write |

## Interaction States

| State | Visual / behavior |
|-------|-------------------|
| List loading | Table `loading` |
| Map loading GeoJSON | Spin overlay on map Card |
| Map empty (no selection) | Basemap + centered Caption “Select an asset to preview” |
| Preview sampling in flight | Disable **Preview sample points**; Spin on map |
| Preview capped | Honesty Alert shows cap; do not request above 500 |
| Upload in flight | Modal OK Button loading |
| Delete 409 | Usage Modal; list unchanged |
| RBAC denied (when enabled) | Existing console error toast / `R.fail` message — no custom auth UI |

## API Surface (console client expectations)

| Method | Path | UI use |
|--------|------|--------|
| GET | `/api/console/geo-assets` | List table |
| GET | `/api/console/geo-assets/{id}/geojson` | Asset + underlay layers (D-05/D-06) |
| POST | `/api/console/geo-assets` multipart | Upload |
| DELETE | `/api/console/geo-assets/{id}` | Delete; handle 409 body with usage hints |
| POST | `/api/console/geo-assets/preview/synthetic` | Capped points; body includes mode config + seed; maxCount ≤ 500 (D-08) |
| GET/POST | preview helper for path/classpath GeoJSON | Exact path naming discretionary if D-06 holds |

Errors: consume `R` envelope messages via `message.error` / Modal body — same as Udfs/Datasources.

## Accessibility & Dual Theme

- Map is decorative for geometry; list remains the accessible primary affordance (keyboard-selectable rows, labeled Buttons).
- Honesty Alert must remain in DOM (not canvas-only text).
- All controls inherit Ant Design focus rings; respect light/dark tokens — map paint uses theme accent/warning resolved at render time.
- `data-testid`s: `nav-geo-assets`, `geo-assets-page`, `geo-assets-upload`, `geo-assets-map`, `geo-assets-honesty-alert`, `geo-synthetic-picker`.
