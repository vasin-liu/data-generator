<objective>
Create the top-level Maven module `data-generator-test-fixtures` that ships reusable synthetic-data
simulation fixtures for Template V2 runs in tests, with zero production credentials. The module
combines YAML Template V2 templates with two minimal static Java helpers (`FixtureTemplates.load`,
`H2Seed.apply`) and provides one embedded integration example per adapter class — reader, writer,
and transform — aligned with the coarse matrix rows defined in plan 01-01. This satisfies TEST-02
(reusable fixture library) and TEST-05 (embedded-first patterns exemplified for at least one reader,
one writer, one transform). Plan 01-03 then references these example classes from the matrix and the
harness, and Playwright reuses the same YAML fixtures (D-19).
</objective>

<threat_model>
STRIDE register (ASVS L1; security_enforcement enabled). This module ships test fixtures consumed in
test scope; the dominant risk is leaking real infrastructure access into the repo (TEST-02).

| STRIDE | Threat | Mitigation in this plan | Severity |
|--------|--------|-------------------------|----------|
| Spoofing | A fixture template impersonates a real datasource by embedding production connection details | Every JDBC URL is `jdbc:h2:mem:`; T2 verify greps for and rejects `jdbc:mysql/postgresql/oracle/sqlserver` and `password=` in fixtures. | High |
| Tampering | Example tests pass trivially (e.g. `assertTrue(true)`) and falsely mark matrix rows covered | Acceptance criteria require concrete row-count/value assertions and a green Surefire run; plan 01-03's summary is result-driven. | Medium |
| Repudiation | Unclear which scenario a fixture belongs to | Scenario-named files (D-17) and matching test class names make provenance explicit. | Info |
| Information disclosure | Real secrets/credentials committed via SQL/CSV/YAML fixtures | No secrets permitted; in-memory H2 only; T2 credential grep gate (TEST-02). Test-jar is test-scope only (D-14), not shipped at runtime. | High |
| Denial of service | Fixtures that contact external hosts hang CI | All fixtures are in-process H2; no network calls; no `@EnabledIf` external gates in the three examples. | Low |
| Elevation of privilege | test-jar leaking onto the runtime classpath of `data-generator-service` | Module is consumed only as `<scope>test</scope>` `<type>test-jar</type>`; the module never depends on `data-generator-service`. | Medium |

**Blocking severities (high) addressed:** credential/production-URL leakage is gated by the T2 grep
check; secret disclosure is prevented by the in-memory-H2-only constraint and test-scope packaging.
</threat_model>
