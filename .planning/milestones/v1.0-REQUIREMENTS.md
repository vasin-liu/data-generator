# Requirements: data-generator v1.0 (ARCHIVED)

**Defined:** 2026-06-17
**Shipped:** 2026-06-23
**Core Value:** Operators can define, extend, and trust data-generation pipelines through uploadable UDFs, richer transforms, and an automated test harness.

## v1 Requirements — Outcomes

### Test Harness

- [x] **TEST-01**: A documented feature matrix exists mapping platform capabilities (readers, writers, transforms, console flows) to test types and owners (`docs/` or `.planning/`) — **Validated** via `.planning/test-matrix.yaml` + `docs/test-feature-matrix.md`
- [x] **TEST-02**: A reusable synthetic data simulation fixture library supports Template V2 runs in tests without production credentials — **Validated** via `data-generator-test-fixtures`
- [x] **TEST-03**: A single CI-oriented entry script runs the harness slice (Maven modules + optional console build) with JDK 25 and project Maven settings — **Validated** via `scripts/verify-harness.ps1`
- [x] **TEST-04**: Harness reports which matrix rows are covered vs pending (machine-readable summary for phased ramp) — **Validated** via `target/test-matrix-summary.json`
- [x] **TEST-05**: Embedded-first integration patterns are documented and exemplified for at least one reader, one writer, and one transform path — **Validated** via fixture example tests
- [x] **TEST-06**: Playwright console smoke path is wired to matrix rows for template edit and job trigger — **Validated** via `harness-verify.yml` / console E2E

### UDF Platform

- [x] **UDF-01**: A unified UDF registry model identifies UDFs by stable ID, type (java-plugin, script, sql), version, and lifecycle state — **Validated** Phase 2
- [x] **UDF-02**: Operators can register Java/PF4J UDF artifacts compatible with existing `data-generator-calcite` plugin loading — **Validated** Phase 2
- [x] **UDF-03**: Operators can register script UDFs (GraalJS and/or Velocity) with schema validation before publish — **Validated** Phase 2
- [x] **UDF-04**: Operators can register SQL/Calcite UDF definitions referenced by Template V2 SQL transforms — **Validated** Phase 2
- [x] **UDF-05**: Console/API supports upload, list, version history, and publish/deprecate for UDF artifacts — **Validated** Phase 3
- [x] **UDF-06**: Template V2 validation rejects references to unknown or unpublished UDF IDs at publish time — **Validated** Phase 3
- [x] **UDF-07**: UDF governance hooks align with secret/template governance — **Validated** Phase 2
- [x] **UDF-08**: Sample UDFs (one per type) ship in-repo with harness tests — **Validated** Phase 3 (`samples/udf-samples/`)

### Transform Enhancement

- [x] **XFORM-01**: Catalog of built-in transform operators is documented and discoverable from console or API metadata — **Validated** `GET /api/console/transforms`
- [x] **XFORM-02**: At least three new high-value built-in operators ship (json, mask, lookup) — **Validated** Phase 4
- [x] **XFORM-03**: SQL transform expression surface supports additional scalar functions/types — **Validated** `V2_JSON_EXTRACT`
- [x] **XFORM-04**: Template V2 schema/version notes document new operator and UDF reference fields — **Validated** Phase 4 docs
- [x] **XFORM-05**: Operator and UDF errors surface actionable messages in run reports and console job detail — **Validated** Phase 4
- [x] **XFORM-06**: Harness matrix includes rows for each new operator and UDF type with passing embedded tests — **Validated** Phase 4–5

### Coverage Ramp

- [x] **COV-01**: Phase-4 coverage target defines minimum matrix completion % and priority tiers (P0/P1/P2 rows) — **Validated** Phase 5
- [x] **COV-02**: P0 matrix rows (core V2 run, UDF publish, three transform types) reach automated green status in CI — **Validated** 7/7 P0 green
- [x] **COV-03**: Console API slice tests expand for UDF and transform metadata endpoints — **Validated** Phase 5
- [x] **COV-04**: Regression gate blocks merge when P0 matrix rows fail — **Validated** `verify-harness.ps1` + `AGENTS.md`
