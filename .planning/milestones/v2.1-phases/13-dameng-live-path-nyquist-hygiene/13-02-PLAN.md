<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator shell env → wrapper script → Maven | Credentials pass through a script that prints diagnostics to the console and to CI logs |
| Repository docs → public/shared distribution | Anything written into docs or scripts is committed and shared; a pasted credential becomes a durable leak |
| Opt-in UAT script → merge gate perception | A script that exits zero when unconfigured would let a non-run be reported as a passed UAT |

## ASVS

- Level: 1
- Block on: high severity threats

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-01 | Information Disclosure | Wrapper script usage and diagnostic output | high | mitigate | Script echoes variable names only; never the password value and never the full JDBC URL, which can carry embedded credentials |
| T-13-03 | Information Disclosure | Committed docs and script content | high | mitigate | Placeholder host, schema, and credential text only; explicit never-commit-secrets warning per D-08; no environment file or sample credential file is created |
| T-13-04 | Elevation of Privilege | P0 merge gate scope | high | mitigate | Acceptance criteria assert `.planning/test-matrix.yaml`, `scripts/verify-harness.ps1`, and workflow files are unmodified and that the new script is not referenced from them; DIAL-03 stays deferred |
| T-13-08 | Repudiation | Unconfigured UAT run reported as pass | high | mitigate | Fail-closed precheck exits 1 with usage before Maven runs; the task verify command inverts on this exact condition, so a silent pass fails the gate |
| T-13-09 | Spoofing | Docs claiming an unobserved live green | medium | mitigate | Docs and SUMMARY state the enable path and expected PASS without asserting a live PASS was observed here; D-05 defines this as the honest outcome |
</threat_model>
