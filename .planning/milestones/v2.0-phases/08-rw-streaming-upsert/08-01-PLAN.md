# Plan 08-01: Chunked CSV Row Source & UTF-8 BOM Parser

## Objective

Implement incremental CSV reading for explicit `CHUNKED`/`STREAMING` execution policies without breaking existing `IN_MEMORY` small-file behavior (RW-01, D-01, D-02, D-09, D-21).

**Output:** `ChunkedCsvRowSource` implementing `ChunkedRowSource`; policy-aware `CsvSourceFactory.create(name, source, policy)` dispatch mirroring `QuerySourceFactory`.

**Downstream:** Plan 08-02 (`depends_on: [08-01]`) mirrors this factory/`ChunkedRowSource` contract for JSON sources — keep create overload and `usesChunkedRead` gate identical so 08-03 registry wiring stays uniform.
