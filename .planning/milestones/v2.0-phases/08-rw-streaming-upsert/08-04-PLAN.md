# Plan 08-04: CSV/JSON Streaming Sinks Per-Chunk Flush

## Objective

Enable large output datasets by flushing CSV/JSON file sinks incrementally per pipeline chunk (RW-02, D-10, D-11).

**Output:** Streaming-aware sink adapters invoked by `SinkWriteExecutor` with append semantics; Excel unchanged.
